# Security Policy

## Supported Versions

We provide security updates and patches for the following versions of OmicGene:

| Version | Supported          |
| :------ | :----------------- |
| `0.1.x` | :white_check_mark: |
| `< 0.1` | :x:                |

---

## Reporting a Vulnerability

The OmicGene team takes the security of computational pipelines and biological data integrity very seriously.

If you discover a security vulnerability or sensitive data exposure issue (e.g., accidental inclusion of private patient health information or credential leaks):

1. **Do not disclose the vulnerability publicly** in issues, pull requests, or discussions.
2. Report the vulnerability privately via **GitHub Security Advisories**:
   - Go to [OmicGene Security Advisories](https://github.com/omicgene/omicgene/security/advisories/new).
   - Alternatively, email the maintainers directly at: **darrehanrasool@gmail.com**.
3. Please include:
   - A detailed description of the vulnerability.
   - Steps to reproduce or proof of concept.
   - Potential impact on users, pipelines, or clinical data integrity.

---

## Response Timeline

- **Initial Acknowledgment**: Within 48 hours.
- **Triage & Assessment**: Within 5 business days.
- **Fix & Public Advisory**: Coordinated release with reporter attribution.
