# Exploratory Research & Reproduction Notebooks

Interactive Jupyter notebooks exploring antimicrobial resistance datasets, variant frequencies, and model reproduction pipelines.

---

## Directory Index

- `01_exploratory_data_analysis.ipynb`: Cohort statistics, lineage distribution, drug resistance correlation heatmaps.
- `02_variant_calling_and_feature_matrix.ipynb`: Extracting non-synonymous mutations in key AMR genes and constructing sparse feature matrices.
- `03_baseline_models_benchmarking.ipynb`: Training and benchmarking Random Forest, Logistic Regression, and XGBoost baselines.
- `04_deep_learning_and_embeddings.ipynb`: Sequence tokenization, ESM-2 embeddings extraction, and neural fine-tuning.
- `05_explainability_and_shap.ipynb`: Feature attribution with SHAP, identifying epistatic interactions and novel candidate resistance mutations.
